# Portfolio website

A simple, static portfolio site — no build step.

- **Name color:** jet black `#0a0a0a`
- **Background:** dimmed warm stone `#c9c5bd`
- **Accent:** amber yellow `#ffb000`

Open `index.html` in a browser to view it. Edit the colors in the `:root` block at the top of `styles.css`, and replace "Your Name", the projects, and the contact links in `index.html`.
