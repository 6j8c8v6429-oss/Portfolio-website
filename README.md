# Portfolio website

A simple, static portfolio site — no build step.

- **Name color:** jet black `#0a0a0a`
- **Background:** darker warm stone `#a39e94`
- **Type:** Archivo (variable width, reacts to the cursor), Geist, Geist Mono
- **Accent:** amber yellow `#ffb000`

Open `index.html` in a browser to view it. Edit the colors in the `:root` block at the top of `styles.css`, and replace "Your Name", the projects, and the contact links in `index.html`.

To personalise: replace "Your Name", the case studies, experience and links in `index.html`, and set your city and time zone in the `CONFIG` block at the top of `script.js`. The case-study numbers are examples; swap in your real results.
